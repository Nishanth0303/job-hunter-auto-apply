## 🌟 Key Features

1. **Top 20 Ranked Jobs Every Day**:
   * Scans and ranks the **Top 20 most-matched jobs** in descending order (Rank #1 at 98% down to 85%).
   * Highlights Top 3 with Gold badges.

2. **Top 8 Indian IT Job Portals**:
   * **Naukri** (Must use - IT services, high-demand PHP & Laravel openings)
   * **LinkedIn Jobs** (MNCs, product companies, and remote roles)
   * **Instahyre** (Curated tech firms and senior engineer positions)
   * **Cutshort** (Startups, modern Laravel & PHP software engineering)
   * **Foundit** (Monster India - enterprise software opportunities)
   * **Indeed** (Direct company career pages)
   * **Hirist** (Premium tech unicorns and high-growth startups)
   * **Wellfound** (AngelList Talent - remote & startup developer positions)

3. **Smart 4-Resume Variant Matching**:
   * **PHP Developer Resume** ➔ `https://nishanth0303.github.io/Nishanth-portfolio/php-dev.html`
   * **Software Developer Resume** ➔ `https://nishanth0303.github.io/Nishanth-portfolio/software-dev.html`
   * **Application Developer Resume** ➔ `https://nishanth0303.github.io/Nishanth-portfolio/application-dev.html`
   * **Full Stack Developer Resume** ➔ `https://nishanth0303.github.io/Nishanth-portfolio/full-stack.html`

4. **1-Click Review & Auto-Apply**:
   * Review Job Description, Fit Analysis, and Tailored Cover Letter.
   * Click **[ Approve & Auto-Apply ]** to mark applied and track timestamp.

5. **Works Everywhere (Local + GitHub Pages)**:
   * Run locally with `node server.js`
   * Or host statically on **GitHub Pages** (`https://nishanth0303.github.io/job-hunter-auto-apply`)

## 📦 How to Push to Your GitHub Repository

Run these commands in PowerShell or Git Bash:

```powershell
cd c:\Users\Windows\Desktop\job-hunter-auto-apply

git init
git add .
git commit -m "feat: Top 20 ranked jobs across Top 8 Indian portals with 4 tailored resumes"
git branch -M main
git remote add origin https://github.com/nishanth0303/job-hunter-auto-apply.git
git push -u origin main --force
```

### Enable GitHub Pages in your Repository:
1. Go to your GitHub repository: `https://github.com/nishanth0303/job-hunter-auto-apply/settings/pages`
2. Under **Build and deployment > Branch**, choose **`main`** and **`/(root)`**, then click **Save**.
3. Your live dashboard is now accessible at:
   👉 **`https://nishanth0303.github.io/job-hunter-auto-apply`**
